About Smart AQI

Smart AQI (Air Quality Intelligence) is a data-driven project using historical AQI data to forecast and visualize pollution patterns. Powered by AI models like LSTM, ARIMA, Prophet, and XGBoost, it provides real-time and predictive insights for environmental planning.

Key Features

📊 Historical Data Analysis

Explore years of AQI records for cities and pollutants.

🤖 AI Forecasting

Predict AQI trends using LSTM, Prophet, and ARIMA.

🚨 Real-Time Alerts

Stay informed with alerts when pollution exceeds safe limits.

🌍 Interactive Dashboards

Visualize and compare air quality metrics easily.
